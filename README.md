# Budget Maison pour Android

Ce depot contient uniquement les versions Android officielles de Budget
Maison. Il ne contient ni le code source ni la configuration Home Assistant.

## Installer l'application

1. Ouvrir la [derniere version](https://github.com/Toyeuu35/Budget-Maison-Releases/releases/latest).
2. Telecharger le fichier `Budget-Maison-<version>.apk`.
3. Ouvrir le fichier telecharge.
4. Si Android le demande, autoriser temporairement le navigateur a installer
   des applications inconnues.
5. Installer Budget Maison, puis se connecter avec Home Assistant.

Pour une mise a jour, telecharger le nouvel APK et l'installer par-dessus la
version existante. La session et les donnees locales sont conservees.

Chaque version fournit aussi un fichier `.sha256` permettant de verifier
l'integrite du telechargement.
